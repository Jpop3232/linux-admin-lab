# linux-admin-lab
## Project Purpose  
This project is designed to practice user managment, SSH skills, and Bash scripting within a Linux enviroment. 
## Project Setup
For this project setup a VM with an Ubuntu server on it. I personally used Oracle VirtualBox. Populate the server with two other users, for the sake of clear labelling one user will be "fullpermission" and the other will be "nopermission" and one will be "somepermission" which will indicate what level of file permission will be configured for them. All users have the password "1234", this is obviously an unacceptable password to have in real life but is done as to keep focus on the project. For this project to work openSSH needs to be installed on the VM.
